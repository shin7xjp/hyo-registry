The Hyo Ecosystem

Hyo packages extend the framework with composable building blocks — from UI rendering and animation to networking, storage, and internationalization.

User Interface

Widgets, layouts, theming, and a complete design system for building native-quality UIs with Lua.

Animation

Tween-based animation engine with easing curves, springs, and tick interpolation.

Navigation

Stack-based navigation, route management, and screen history for multi-screen applications.

Networking

REST HTTP client, async fetch, JSON handling, and network utilities.

Storage

Key-value persistent storage, file caching, and local data management.

Internationalization

Localization, pluralization, string interpolation, and multi-language support.
